About

RLV Mission Control is a local desktop dashboard for the reusable launch vehicle flight simulator. Simulations execute entirely on this machine — no telemetry leaves your computer unless you configure a remote backend URL above.

Aerodynamic Model Validation
Tier 1 Physical-Sanity Checks

Checks the aerodynamic model against classical aerodynamic theory (drag rise shape, lift-curve symmetry, published slender-body bounds, interpolation correctness) — not against wind-tunnel, CFD, or real flight data for this specific vehicle. See aero_validation.py for the full method and caveats.
